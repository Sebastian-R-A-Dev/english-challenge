# English Challenge - Cursor Skill

## Contexto General

Debes crear una aplicación moderna usando Next.js llamada **English Challenge**.

La aplicación será un reto interactivo de preguntas en inglés donde los jugadores podrán medir su nivel, competir entre sí y demostrar quién es el mejor.

La experiencia debe sentirse:
- Gamer
- Futurista
- Tecnológica
- Competitiva
- Moderna
- Profesional

La aplicación debe parecer un producto real de alto nivel para portafolio profesional.
